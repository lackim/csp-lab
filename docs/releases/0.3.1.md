# csp-lab 0.3.1

Faster, more predictable lab startup. Use package and native image version
0.3.1 together: the probe now accepts several targets, which 0.3.0 images reject.

- Demo-only labs and `csp-lab up` wait up to 30 seconds for nodes 2 and 3,
  like labs with custom nodes, rather than pinging each node once.
- Readiness and `Lab.diagnose()` ping all nodes with one probe container, in
  concurrent batches of four. Slow nodes share one budget; a ten-node diagnose
  takes about a second. CLI `doctor` and MCP keep one probe per node so a lab
  started by an earlier version stays usable.
- The managed image is pulled only when it is not present locally, matching
  custom images. Starting a lab no longer needs registry access each time.
- A shared pytest lab that fails to start is not started again for every
  remaining test of that configuration; they fail at once with the first error.
- The managed image runs as a non-root user. The package ships `py.typed` and
  exports `TopologyResult`, `DiagnoseResult`, and `StatusResult`.
